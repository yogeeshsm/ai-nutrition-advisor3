## 🎓 Technical Highlights

### Machine Learning
- **Model:** MobileNetV2 (efficient, mobile-optimized)
- **Framework:** TensorFlow 2.15 + Keras
- **Weights:** ImageNet (pre-trained)
- **Parameters:** ~3.5M (lightweight)
- **Size:** ~14MB (fast download)
- **Inference:** 1-2 seconds on CPU

### Backend
- **Framework:** Flask 3.0
- **Language:** Python 3.8+
- **Image Processing:** Pillow (PIL)
- **Numerical:** NumPy
- **API:** RESTful JSON

### Frontend
- **HTML5** - Semantic structure
- **CSS3** - Modern styling, animations
- **JavaScript ES6** - Async/await, fetch API
- **Bootstrap 5** - Responsive framework
- **Font Awesome** - Icons

### Algorithms
- **Food Recognition:** Deep neural network
- **Portion Estimation:** Pixel coverage analysis
- **Nutrition Scaling:** Linear interpolation
- **Assessment:** Percentage-based thresholds
